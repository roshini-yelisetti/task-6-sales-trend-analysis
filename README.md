# Task 6 - Sales Trend Analysis Using Aggregations

## Objective
Analyze monthly revenue and order volume using SQL aggregation functions.

## Tools Used
- MySQL Workbench
- SQL

## Dataset
Sample Superstore Dataset

## Analysis Performed
- Monthly Revenue Analysis
- Monthly Order Volume Analysis
- Revenue and Order Volume Comparison
- Top 3 Months by Sales
- Year-wise Revenue Analysis

## SQL Concepts Used
- GROUP BY
- ORDER BY
- SUM()
- COUNT(DISTINCT)
- YEAR()
- MONTH()

## Outcome
Learned how to aggregate sales data and analyze monthly trends using SQL.
